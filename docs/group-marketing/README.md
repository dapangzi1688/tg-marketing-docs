# 群组营销概览

**TG群组自动营销**（当前版本见程序启动横幅，如 v6.1.x）面向已加入的 Telegram **群组/超级群**做营销群发与群管理。

## 主菜单

```
1. 综合功能    17 个子功能（加群、检测、解除双向等）
2. 群发
   ├─ 1. 机器人群发   词库随机文本发群
   └─ 2. 小号群发     从频道转发广告到群
3. 更新
0. 退出
```

详见 [主菜单说明](main-menu.md)。

## 核心能力

| 能力 | 入口 |
|------|------|
| 机器人群发 | 群发 → 机器人群发 |
| 小号群发（频道转发） | 群发 → 小号群发 |
| 账号检测 / 双向 | 综合 → 01.检测账号 |
| 解除双向 | 综合 → 12.解除双向 |

## 必备文件（群发）

| 文件 | 用途 |
|------|------|
| `botconfig.txt` | 机器人用户名（每行一个机器人用户名或者bot-token） |
| `广告.txt` | 小号群发：频道消息链接；机器人群发：日志关联 |
| `config/Configuration.ini` | 授权与 channel_ID 等 |
