# 群组营销 — 配置文件

## botconfig.txt

**机器人群发**与 **17.转发消息** 共用此文件，但用途不同：

| 功能 | 用途 |
|------|------|
| 机器人群发 | 每行一个 **@Bot 用户名**，作为按顺序循环的**文本词库**发往群组（每次最多取 3 条用空格拼接） |
| 17.转发消息 | 每行一个 **@Bot 用户名**，作为**转发目标**（将 `广告.txt` 中的频道消息转发给该 Bot） |

```
@BotUsername1
@BotUsername2----备注可忽略
```

* 仅使用每行 `----` **前面**的部分，格式化为 `@用户名`
* **不支持**用 bot token 登录；token 写在行内不会被使用
* 支持 `https://t.me/BotName` 形式，会自动转为 `@BotName`

## 广告.txt

小号群发、引用群发、17.转发消息、机器人群发日志等共用。

```
https://t.me/your_channel/123
https://t.me/your_channel/124----分流标记
```

| 场景 | 说明 |
|------|------|
| 小号群发 | 有有效链接时按链接转发；**为空或不存在**时回退读取 `channel_ID` 频道全部消息 |
| 引用群发 | 有有效链接时**全量轮发**（按文件顺序）；为空或不存在时回退 `channel_ID` |
| 17.转发消息 | 必填；含 `----` 的行进入分流模式 |
| 机器人群发 | 可选；用于日志文件名关联（取链接末段或 `----` 前段） |

## 评论内容.txt

**引用群发**专用：跨对话引用时发出的评论文案。

* 多条用连续 **21 个及以上 `#`** 分隔
* 每次发送随机取一条
* 文件不存在或为空时无法进入引用群发

## 群组.txt

加群、筛选等功能的群组链接列表。

## config/Configuration.ini

```ini
client_token=你的授权码
client_code=你的端码
api_id=2040
api_hash=...
channel_ID=频道用户名或0
delay=0
header=转发
```

| 字段 | 说明 |
|------|------|
| `channel_ID` | 小号/引用群发：`广告.txt` 为空时的广告源频道；日志上传时的频道名来源之一 |
| `delay` | 小号/引用群发等功能的默认发送间隔（秒） |
| `header` | 小号群发：`转发` / `直发`；引用群发运行后会写成 `引用`（发送方式固定为引用回复） |

## 异常广告id.txt

可选：记录发送异常的频道消息 ID，用于跳过问题广告（默认读写功能关闭）。程序启动时可能清空此文件。

## 授权相关（非 ini 文件）

群发加载账号数量上限 **MaxCount** 由授权服务端下发（默认 50），非配置文件字段。
