# 群组营销 FAQ

## 为什么没有加载到账号？

* session 不在 `账号/` 或已移入 `异常账号/`
* 其他框架协议 session 转换失败
* 同一 session 在其他地方同时登录导致失效
* 已加载账号数达到授权上限 **MaxCount**（默认 50）

## 群发后很多号进双向限制账号？

* 间隔太短、单号群太多、同 IP 账号过多
* 见 [降低封号风险建议](../shared/safety-tips.md)

## no such column: version

其他框架协议 session 被本框架协议直接读取导致。软件会自动转换；失败请用手动 **16.py转换tl** 或移出损坏文件。

## Constructor ID / TL 解析错误？

多为 Telegram 协议层与个别群组/频道实体不兼容。可尝试：减少异常群、升级至当前程序版本，或联系客服获取最新 build。

## 程序行为与旧版 exe 不一致？

请使用启动横幅所示的最新版本；旧版可能缺少 session 修复、双向验证、定时运行、限制群组日志等逻辑。

## 定时运行怎么用？

机器人群发与小号群发在配置完主要参数后，会询问「是否开启定时运行」。输入如 `1-20` 表示每天 1:00 上线、20:00 全部下线；`22-6` 表示跨天。定时下线只断开连接，不把账号移入异常文件夹。
