## 综合功能（01～17）

| 序号 | 功能 | 说明 |
|------|------|------|
| 01 | 检测账号 | 冻结检测 + 可选 SpamBot 双向检测 |
| 02 | 修改资料 | 头像、用户名、简介、隐私等 |
| 03 | 加入群组 | 按链接批量加群 |
| 04 | 导出群组 | 导出已加群组列表 |
| 05 | 采集群组 | 循环采集群组链接 |
| 06 | 筛选群组 | 按条件筛选群组 |
| 07 | 取验证码 | 读取 Telegram 登录验证码 |
| 08 | 删联系人 | 批量删除联系人 |
| 09 | 删对话框 | 批量删除对话 |
| 10 | 批量退群 | 退出已加群组 |
| 11 | 共享连接 | Chatlist 共享连接 |
| 12 | 解除双向 | 通过 @SpamBot 申诉 |
| 13 | 生成账号 | 新建 session |
| 14 | tdata转换 | Desktop tdata → session |
| 15 | 群组数量 | 查看自己创建的频道/群数量 |
| 16 | py转换tl | 外部目录其他框架协议 session 批量转本框架协议到 `账号/` |
| 17 | 转发消息 | 将频道广告转发给 Bot（非发群） |

详见 [综合功能一览](features-overview.md)。
