# 小号群发

从指定**频道消息**转发到账号已加入的群组（与机器人群发的「纯文本词库」模式不同）。

## 前置条件

* `账号/` 内有 session
* 广告来源（二选一）：
  * **`广告.txt`**：每行一条频道消息链接，如 `https://t.me/频道用户名/消息ID`
  * **`config/Configuration.ini` 的 `channel_ID`**：当 `广告.txt` 为空或不存在时，从该频道拉取全部消息作为广告
* 首次启动或配置为空时，软件会交互询问：发送方式（转发/直发）、发送间隔、广告源频道等

## 启动流程

1. 主菜单 → `2.群发` → `2.小号群发`
2. 按提示配置发送方式、间隔等（若 ini 中已有有效 `delay`、`channel_ID`、`header` 则直接使用）
3. 若授权开启日志上传（`IsLogUp=1`），还需配置有效的 `LogBot` 与上传间隔

账号加载数量上限 **MaxCount** 由授权服务端下发，非交互输入。

## 发送逻辑

* 读取广告（`广告.txt` 或 `channel_ID` 频道），向各群 `forward_messages`
* **转发**（`header=转发` / 方式 1）：保留转发来源
* **直发**（`header=直发` / 方式 2）：隐藏转发来源（drop_author）
* 遇 `UserBannedInChannelError` 时同样会 **SpamBot 双向验证**：
  * 未双向 → 跳过该群继续
  * 已双向 → 移入 `双向限制账号/`

## 日志

* `log/群发日志.txt` — 总日志
* `log/群发日志记录/` — 按**广告消息 ID** 分文件（如 `123.txt`）
* `可能异常的群组.txt`（程序根目录）— 发送异常时记录的群组

> 程序每次启动时会清空 `log/群发日志记录/` 下已有文件。
