# 小号群发

从指定**频道消息**转发到账号已加入的群组（与机器人群发的「纯文本词库」模式不同）。

## 前置条件

* `账号/` 内有 session
* 广告来源（二选一）：
  * **`广告.txt`**：每行一条频道消息链接，如 `https://t.me/频道用户名/消息ID`
  * **`config/Configuration.ini` 的 `channel_ID`**：当 `广告.txt` 为空或不存在时，从该频道拉取全部消息作为广告
* 首次启动或配置为空时，软件会交互询问：发送方式（转发/直发）、发送间隔、广告源频道等

## 启动流程

1. 主菜单 → `2.群发` → `2.小号群发`
2. 按提示配置发送方式、间隔等（若 ini 中已有有效 `delay`、`channel_ID`、`header` 则直接使用）
3. 若授权开启日志上传（`IsLogUp=1`），还需配置有效的 `LogBot` 与上传间隔
4. 可选：**是否开启定时运行**（见下文）

账号加载数量上限 **MaxCount** 由授权服务端下发，非交互输入。

## 定时运行（可选）

配置完发送参数后，程序会询问：

```
是否开启定时运行(y/n,默认n):
请输入运行时间段(24小时制,例如1-20表示1:00-20:00运行):
```

| 输入示例 | 含义 |
|----------|------|
| `n` 或直接回车 | 不启用，与旧版一样持续运行 |
| `1-20` | 每天 **1:00** 全部账号上线群发，**20:00** 全部下线 |
| `22-6` | **跨天**：22:00 上线，次日 6:00 下线 |

说明：

* 起止小时相同（如 `8-8`）视为**全天运行**，不启用定时
* 到达下线时刻会打印「**定时下线**」，断开连接；**不会**把账号移入 `异常账号/`
* 下线后程序等待下一运行时段再自动上线，可长期挂机
* 时段外启动时，会一次性等待到下次上线时刻（不每分钟刷屏）

## 发送逻辑

* 读取广告（`广告.txt` 或 `channel_ID` 频道），向各群 `forward_messages`
* **转发**（`header=转发` / 方式 1）：保留转发来源
* **直发**（`header=直发` / 方式 2）：隐藏转发来源（drop_author）
* 遇 `UserBannedInChannelError` 时同样会 **SpamBot 双向验证**：
  * 未双向 → 跳过该群继续
  * 已双向 → 移入 `双向限制账号/`
* 遇 `ChatWriteForbiddenError`（群组禁止发言）→ 退出该群，并将群用户名**追加**写入 `log/限制群组.txt`
* 群发过程中账号**异常下线**（如授权失效、被顶号、断开连接、账号冻结等）→ 将该账号当前全部待发群用户名**追加**写入 `log/可能注销账号群组.txt`（定时下线不写入）

## 日志

* `log/群发日志.txt` — 总日志
* `log/群发日志记录/` — 按**广告消息 ID** 分文件（如 `123.txt`）
* `log/限制群组.txt` — 禁止发言被退群的群组用户名（纯用户名，一行一个，追加不覆盖）
* `log/可能注销账号群组.txt` — 账号异常下线时记录的该账号全部群组用户名（追加不覆盖）

> 程序每次启动时会清空 `log/群发日志记录/` 下已有文件。
