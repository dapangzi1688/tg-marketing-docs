# 机器人群发

向账号已加入的、带 `@username` 的群组/超级群发送**随机拼接的 @Bot 文本**（非 Bot API 发消息）。

## 前置条件

* `账号/` 内有已登录 session
* `botconfig.txt` 非空（每行一个 @Bot 用户名,同时后端需登录此文件中的机器人）
* 建议准备 `广告.txt`（用于 `log/群发日志记录/` 分文件命名）

## 启动流程

1. 主菜单 → `2.群发` → `1.机器人群发`
2. 按提示输入：
   * **群发间隔（秒）**：默认 40，建议 90～180 降低双向风险
   * **是否开启整批重启（Y/N）**：默认 **N**。选 **Y** 后继续询问：
     * **每个账号多少轮后重启**：默认 **50**，直接回车即 50 轮
     * **整批重启前暂停（分钟）**：默认 **10**，直接回车即停 10 分钟；填 **0** 表示马上重启
   * **群组列表多少轮刷新一次**：默认 100（只重新拉群列表，不会因此暂停）
   * **是否删除原消息（Y/N）**：默认 **Y**，发送成功后删除该条消息；选 **N** 则保留在群内
   * **发送文本是否加遮罩（Y/N）**：默认 **N**。选 **Y** 后，整条消息（含随机前缀）以 Telegram 剧透遮罩发出，群里显示为黑条，点击后才显示正文
3. 可选：**是否开启定时运行**（见下文）

账号加载数量上限 **MaxCount** 由授权服务端下发（默认 50），启动时不在此步骤询问。

## 定时运行（可选）

完成上述参数后，程序会询问是否开启定时运行，格式与小号群发相同：

* 例：`1-20` → 每天 1:00 上线、20:00 全部下线
* 例：`22-6` → 跨天运行（22:00 至次日 6:00）
* 定时下线仅断开连接，**不**移入异常账号文件夹；到点打印「定时下线」

## 发送逻辑

1. 拉取账号已加群列表（带 username 的 megagroup / chat）
2. 每群：从 `botconfig.txt` 随机抽最多 3 条拼成正文
3. 正文前加 **6～10 位随机字母数字 + 空格**（避免内容完全一致）
4. 若开启文本遮罩，整段文本使用剧透实体发送
5. 发送后按启动选项决定是否删除消息（默认删除，降低群内残留；选 N 则保留）
6. 群与群之间、以及轮与轮之间，都等待「群发间隔」秒
7. 开启整批重启时，每个账号跑完设定轮数后下线；整批结束后按设定的分钟数暂停，再重新拉起客户端

## 异常与归档

| 情况 | 处理 |
|------|------|
| `UserBannedInChannelError` | 先 @SpamBot 验证；仅单群受限则剔除该群，确认双向则移入 `双向限制账号/` |
| `ChatWriteForbiddenError` | 禁言/无发言权限，剔除该群，用户名追加写入 `log/限制群组.txt` |
| FloodWait | 等待后重试或跳过（视秒数） |
| 慢速模式 | 记录到 `log/慢速模式群组.txt`，跳过 |
| 账号异常下线 | 将该账号全部群组用户名追加写入 `log/可能注销账号群组.txt`，移入 `异常账号/` |
| 无可发群 | 移入 `无群组账号/` |
| 定时下线 | 到点 cancel 任务，断开连接，不归档为异常 |

## 日志

* `log/群发日志记录/` — 按 `广告.txt` 各行末段（或 `----` 前段）分文件
* `log/账号下线日志.txt` — 账号停止原因（含「定时下线」）
* `log/限制群组.txt` — 禁止发言的群组用户名（追加不覆盖）
* `log/可能注销账号群组.txt` — 账号异常下线时记录的全部群组用户名（追加不覆盖）
* `双向限制账号.txt`（程序根目录）— 待搬运清单（后台线程兜底）
* `无用账号.txt`（程序根目录）— 待移入异常账号（兜底）
