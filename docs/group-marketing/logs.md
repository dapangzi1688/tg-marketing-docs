# 群组营销 — 日志说明

| 路径 | 内容 |
|------|------|
| `log/群发日志.txt` | 小号群发总日志 |
| `log/群发日志记录/` | 分文件记录（按广告消息 ID 命名，如 `123.txt`） |
| `log/账号下线日志.txt` | 账号停止、归档原因（含「定时下线」） |
| `log/加群日志.txt` | 加群结果 |
| `log/慢速模式群组.txt` | 触发 SlowMode 的群（机器人群发） |
| `log/限制群组.txt` | 禁止发言（`ChatWriteForbiddenError`）的群组用户名，机器人群发与小号群发共用，**追加不覆盖** |
| `log/可能注销账号群组.txt` | 群发过程中账号**异常下线**时，该账号全部待发群用户名，**追加不覆盖**（定时下线不写入） |
| `双向限制账号.txt` | 待移入双向文件夹的账号名（程序根目录，兜底） |
| `无用账号.txt` | 待移入异常账号（程序根目录，机器人群发兜底） |

> **注意**：程序每次启动时会清空 `log/群发日志记录/` 目录下已有文件。`限制群组.txt`、`可能注销账号群组.txt` 不会被自动清空。

## 排查建议

1. 账号突然消失 → 查 `log/账号下线日志.txt` 与 `异常账号/`、`双向限制账号/`
2. 某群始终跳过 → 搜群发日志中的 Flood、慢速、禁言关键字；或查 `log/限制群组.txt`
3. 账号疑似被注销/顶号 → 查 `log/可能注销账号群组.txt` 找回该号曾加入的群列表
4. 全部账号未加载 → 查 session 是否在 `异常账号/`，或其他框架协议未转换成功，或是否已达 MaxCount 上限
