# 群组营销 — 日志说明

| 路径 | 内容 |
|------|------|
| `log/群发日志.txt` | 小号群发总日志 |
| `log/群发日志记录/` | 分文件记录（常按广告 ID 命名） |
| `log/账号下线日志.txt` | 账号停止、归档原因 |
| `log/加群日志.txt` | 加群结果 |
| `log/慢速模式群组.txt` | 触发 SlowMode 的群 |
| `双向限制账号.txt` | 待移入双向文件夹的账号名（兜底） |
| `无用账号.txt` | 待移入异常账号（机器人群发兜底） |

## 排查建议

1. 账号突然消失 → 查 `log/账号下线日志.txt` 与 `异常账号/`、`双向限制账号/`
2. 某群始终跳过 → 搜群发日志中的 Flood、慢速、禁言关键字
3. 全部账号未加载 → 查 session 是否在 `异常账号/`，或是否 Pyrogram 未转换成功
