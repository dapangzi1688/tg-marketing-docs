# 引用群发

向已加入的群发送**评论文案**，并**跨对话引用**广告源频道中的广告消息（效果类似回复频道里的那条广告）。对应旧版 `qunfa2` 的引用回复模式；账号调度、异常处理、日志上传与小号群发共用同一套逻辑。

## 前置条件

* `账号/` 内有 session
* **`评论内容.txt`**（必填）：引用时发出的文本；多条用连续 **21 个及以上 `#`** 分隔，每次发送随机取一条
* 广告来源（二选一，与小号群发相同）：
  * **`广告.txt`**：每行一条频道消息链接，如 `https://t.me/频道用户名/消息ID` → **全量轮发**（按文件顺序逐条，不随机抽一条）
  * **`channel_ID`**：当 `广告.txt` 为空或不存在时，从该频道拉取全部消息作为广告

示例 `评论内容.txt`：

```
不错，支持一下
#####################
好内容，顶一下
#####################
有意思，收藏了
```

## 启动流程

1. 主菜单 → `2.群发` → `3.引用群发`
2. 配置发送间隔、随机延迟、广告源频道（发送方式固定为引用回复，无需选转发/直发）
3. 若授权开启日志上传（`IsLogUp=1`），配置 `LogBot` 与上传间隔
4. 可选：定时运行（规则与小号群发相同）

## 发送逻辑

* 对每个已加入的超级群：随机取一条评论 → 发送文本，并引用广告频道中的目标消息
* 群组/频道支持 Telegram **多用户名**（主字段 `username` 为空时从 `usernames` 取可用名）
* 异常处理对齐小号群发：禁言退群、Flood、慢速、双向 SpamBot 验证、付费发言、话题关闭等
* 广告消息失效（`MessageIdInvalid`）→ 跳过该条广告，继续下一条

## 日志与上传

与小号群发一致：

* `log/群发日志记录/{广告消息ID}.txt` — 成功发送链接
* `log/群发日志.txt` — 总日志
* `log/限制群组.txt` / `log/可能注销账号群组.txt`
* 日志上传：到期后从**当前在线账号**中随机选一个上传到 LogBot
