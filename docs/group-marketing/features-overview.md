# 群组营销 — 综合功能说明

以下为「综合功能」各菜单简要说明，操作均在软件内按提示进行。

## 01 检测账号

加载所有 session → 检测冻结 → 可选 SpamBot 双向检测 → 异常账号自动移走。

## 02 修改资料

批量修改头像、用户名、个人简介、隐私设置等。

## 03 加入群组

从 `群组.txt` 等链接列表批量加入群组，日志见 `log/加群日志.txt`。

## 04 导出群组

导出当前账号已加入的群组 username 列表。

## 05 采集群组

通过搜索机器人等循环采集群组链接，写入 `采集的群组链接.txt`。

## 06 筛选群组

按成员数、是否限制等条件筛选群组。

## 07 取验证码

用于新登录 session 时读取 Telegram 发来的验证码。

## 08 删联系人 / 09 删对话框

批量清理联系人或对话，降低账号「营销痕迹」。

## 10 批量退群

按列表退出不需要的群组。

## 11 共享连接

管理 Telegram Chatlist 共享链接，文件夹 `共享链接/`。

## 12 解除双向

向 @SpamBot 发起申诉流程，详见 [双向限制与解除](../shared/spam-restriction.md)。

## 13 生成账号 / 14 tdata转换 / 16 py转换tl

* **13**：交互式注册新 session  
* **14**：Telegram Desktop 的 tdata 转 session  
* **16**：手动将其他框架协议 session 转为本框架协议（加载时也会自动转换）

## 15 群组数量

统计自己创建的频道/群组数量。

## 17 转发消息

从 `botconfig.txt`、`广告.txt` 读取配置，向群组转发消息（综合内独立转发流程，支持分流/单发等模式）。
