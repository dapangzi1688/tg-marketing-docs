# 更新记录

## 文档

* 初版：建立 TG营销软件 GitBook 文档结构（群组营销 + 频道营销）
* 同步群发新功能：定时运行、限制群组日志、可能注销账号群组日志
* 机器人群发：整批重启改为先询问是否开启；开启后默认 50 轮，批次之间默认暂停 10 分钟（可改为 0 分钟立即重启）；可选发送文本遮罩（Telegram 剧透）
* 机器人群发正文改为按 `botconfig.txt` 顺序循环取最多 3 个 @Bot（全局共用游标）
* 17.转发消息分流模式取消账号与机器人 1 对 1 限制，改为按账号下标循环分配，同一账号串行转发多个 Bot
* 新增**引用群发**：评论文本 + 跨对话引用频道广告；`广告.txt` 全量轮发；`评论内容.txt`；日志上传与小号群发一致

## 群组营销程序（参考）

* v6.1.x：Session 自动转换、双向 SpamBot 多语言验证、机器人群发随机前缀等
* 近期：机器人群发 / 小号群发支持**定时运行**（如 `1-20` 表示 1:00 上线、20:00 全部下线，支持跨天如 `22-6`）；新增 `log/限制群组.txt`、`log/可能注销账号群组.txt`
* 机器人群发支持按轮数整批重启（默认 50 轮、批次间默认暂停 10 分钟）和发送文本遮罩；@Bot 文本改为顺序循环
* 转发消息分流模式按账号循环分配机器人，不再要求账号数不少于机器人数
* 群发菜单新增 **3.引用群发**（评论 + 引用广告；全量轮发；多用户名兼容）
