# 频道挂载

菜单 **11.频道挂载**，用于创建或管理 Telegram **频道**，并设置简介、挂载消息链接等（便于评论引流到自己的频道）。

## 典型用途

* 批量创建频道并设置 username / 简介
* 将指定消息链接「挂载」到频道展示
* 配合评论营销，把流量导向自有频道

## 前置条件

* `账号/` 内账号有创建频道权限且未触发限制
* 按软件提示准备消息链接（`t.me/频道/消息ID` 格式）

## 注意事项

* 随机 username 生成失败时需重试或手动调整
* 创建频道过多可能触发 FloodWait，软件内有等待上限
* 须遵守 Telegram 对频道命名与内容的规定
