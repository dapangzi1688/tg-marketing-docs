# 主动发表评论

菜单 **05.发表评论**，多账号长期运行，向已订阅且**允许评论**的频道帖子发表评论。

## 前置条件

* `账号/` 内有可用 session
* 账号已订阅目标频道（可用 03.加入频道）
* 评论内容来源（二选一或组合）：
  * 从指定**广告频道**读取消息作为评论内容
  * 从 `广告.txt` 读取链接对应消息

## 运行特点

* 多账号并发，自动跳过不可评论、被禁言、私密频道
* 记录已评论频道/帖子，避免重复评论
* FloodWait 超限会等待或跳过（有最大等待上限）
* 异常账号移入 `异常账号/` 等文件夹（与群组营销相同规范）

## 主要日志（log/）

| 文件 | 说明 |
|------|------|
| `评论记录.txt` | 总评论记录 |
| `评论记录-{消息ID}.txt` | 按广告消息分文件记录 |
| `被禁言的频道.txt` / `禁止发言的频道.txt` | 无法评论的频道 |
| `不存在以及被T频道.txt` | 失效或已被踢频道 |
| `上传日志.txt` | 日志上传记录 |

## 注意事项

* 评论频率过高易触发双向或频道禁言，请适当加大间隔
* 部分频道仅会员/Stars 可评论，会自动跳过并记录
