# 频道营销 — 综合功能说明

## 01 采集频道

通过搜索机器人等采集频道链接，写入采集列表文件（如 `采集的频道链接.txt`）。

## 02 筛选频道

筛选出可评论、开放评论的频道，结果可用于后续加频道与评论。

## 03 加入频道

从 `频道.txt` 批量订阅频道。

## 04 导出频道

导出账号已订阅的频道 username 列表。

## 06 检测账号 / 07 修改资料 / 08 批量退群 / 09 解除双向

行为与群组营销同名功能一致，参见 [群组营销综合功能](../group-marketing/features-overview.md) 对应条目。
