# 频道营销概览

**TG频道自动营销**（当前版本见启动横幅，如 v2.0.x）面向 Telegram **频道（Channel）** 的采集、加入与**评论营销**。

## 功能菜单（0～12）

```
01.采集频道    02.筛选频道    03.加入频道    04.导出频道    05.发表评论
06.检测账号    07.修改资料    08.批量退群    09.解除双向    10.一次评论
11.频道挂载    12.检测更新
0.退出
```

详见 [主菜单说明](main-menu.md)。

## 与群组营销的区别

| 对比项 | 群组营销 | 频道营销 |
|--------|----------|----------|
| 目标 | 群组内发消息 | 频道帖子下评论 |
| 主程序 | TG群组自动营销 | TG频道自动营销 |
| 核心群发 | 机器人群发 / 小号群发 | 主动发表评论 / 一次评论 |
| 列表文件 | 群组.txt | 频道.txt |

## 核心能力

| 能力 | 菜单 |
|------|------|
| 长期自动评论 | 05.发表评论 |
| 单次批量评论 | 10.一次评论 |
| 频道创建/挂载 | 11.频道挂载 |
| 账号与双向 | 06 / 09 |
