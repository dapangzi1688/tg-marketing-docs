# 频道营销 — 主菜单

| 序号 | 功能 | 说明 |
|------|------|------|
| 01 | 采集频道 | 循环采集频道链接 |
| 02 | 筛选频道 | 按条件筛选可评论频道 |
| 03 | 加入频道 | 从 `频道.txt` 等批量订阅频道 |
| 04 | 导出频道 | 导出已订阅频道列表 |
| 05 | 发表评论 | **主动发表评论**（长期运行、多账号） |
| 06 | 检测账号 | 加载 session + 可选双向检测（逻辑同群组 01） |
| 07 | 修改资料 | 批量改资料 |
| 08 | 批量退群 | 退出频道/群组 |
| 09 | 解除双向 | @SpamBot 申诉 |
| 10 | 一次评论 | **单次任务**批量评论 |
| 11 | 频道挂载 | 创建/配置频道并挂载内容 |
| 12 | 检测更新 | 自动检查并下载新版本 |
| 0 | 退出 | 退出程序 |

## 常用工作流

```
采集/筛选 → 加入频道 → 检测账号 → 05发表评论 或 10一次评论
```

需要自有频道承载广告时，可使用 **11.频道挂载**。
