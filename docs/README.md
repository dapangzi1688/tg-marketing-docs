# TG营销软件

欢迎使用 **TG营销软件** 使用文档。本系列产品基于 Telethon 用户号（MTProto），用于 Telegram 上的合规营销与运营辅助。

## 产品线

| 产品 | 入口程序 | 主要场景 |
|------|----------|----------|
| **群组营销** | `TG群组自动营销.exe` | 加群、群发、群组采集与筛选 |
| **频道营销** | `TG频道自动营销.exe` | 加频道、频道评论、频道挂载 |

两套软件**独立安装、独立授权**，账号 session 格式与文件夹规范相同，可共用本文档中的 Session / 双向限制等章节。

## 重要提示

* 请遵守所在地法律法规与 Telegram 服务条款。
* **同一 `.session` 文件不得同时在多个客户端登录**，否则会导致 session 失效（AuthKeyDuplicated）。
* 营销频率过高易触发双向限制，请参阅 [降低封号风险建议](shared/safety-tips.md)。
