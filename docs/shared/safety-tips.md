# 降低封号风险建议

以下适用于**群组营销**与**频道营销**。

## 频率与负载

| 建议 | 说明 |
|------|------|
| 拉大间隔 | 机器人群发建议 90～180 秒/群，而非默认 40 秒 |
| 限制轮次 | 每账号每天 1～3 轮即可，勿 24 小时连轴转 |
| 控制群/频道数 | 单号不要挂几百个目标一次性扫完 |

## 账号与环境

* 新号先养 3～7 天再营销
* 同 IP 建议 1～3 个号
* 一机一号一 IP 最理想
* 避免廉价机房段、共享代理

## 内容

* 词库/广告尽量**整句变化**，不要只有前缀随机
* 避免同一链接、同一结构反复刷
* 机器人群发「发完即删」可能增加脚本特征，按实际效果评估

## 被限制之后

1. **停发** 24～72 小时  
2. 使用 **解除双向** 或手动找 SpamBot  
3. 不要立刻换号加大频率

## 检测而非硬顶

出现 FloodWait 时按提示等待；连续 Flood 的号应下线休息。
