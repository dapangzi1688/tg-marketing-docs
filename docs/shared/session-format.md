# Session 协议与转换

## 问题现象

加载 session 报错：

```
no such column: version
```

## 原因

其他框架协议的 session 数据库列名与本框架协议不兼容（其他框架协议用 `number`，本框架协议查 `version`）。

## 自动处理（推荐）

在 `账号/` 目录加载时，`load_clients()` 连接前会：

1. 识别 session 格式（其他框架协议 / 本框架协议 / invalid）
2. 其他框架协议 → 在 `账号/` **原地**转为本框架协议并验证
3. 无效文件 → 移入 `异常账号/`

## 手动转换

**群组营销** 综合菜单 → **16.py转换tl**：

1. 输入**外部目录**（存放其他框架协议 session 的文件夹，源文件不会被删除）
2. 扫描其中的其他框架协议 session，转换后写入 `账号/`
3. 若 `账号/` 下已有同名 session，会先删除目标再写入

## 旧版本框架协议 session

缺少 `version` 表的旧本框架协议文件会自动补表并验证，无需手动操作。

## 注意

* 自动转换失败时，`账号/` 内源文件可能已被删除，请提前备份
* 同一 session 不要在转换过程中被其他程序占用
