# 双向限制与解除

## 什么是双向限制

Telegram 限制账号向**非互为联系人**的用户发私信，营销中常表现为：群发/评论频繁后账号被限。

## 官方检测方式

向 [@SpamBot](https://t.me/SpamBot) 发送 `/start`：

| SpamBot 回复特征 | 含义 |
|------------------|------|
| 含「Good news」「好消息」「没有限制」等 | 账号正常 |
| 含「limited」「限制」「共同联系人」等 | 账号受限 |

软件内 `check_spam_bot` 支持**多语言关键词**匹配（忽略大小写）。

## 软件内相关功能

| 产品 | 检测双向 | 解除双向 |
|------|----------|----------|
| 群组营销 | 01.检测账号 → 可选 `y` | 12.解除双向 |
| 频道营销 | 06.检测账号 → 可选 `y` | 09.解除双向 |
| 机器人群发 / 小号群发 | 某群报错后先 SpamBot 验证，避免单群禁言误判为双向 | — |

## 解除双向（菜单）

1. 加载账号
2. 向 SpamBot 发送 `/start`
3. 按提示点击「This is a mistake」类按钮并填写英文说明
4. 等待审核（常见 24～72 小时，因号而异）

## 归档

确认双向的 session 移入 `双向限制账号/`。
