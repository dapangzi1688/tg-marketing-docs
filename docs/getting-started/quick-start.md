# 快速开始

## 1. 选择产品

| 产品 | 程序 | 典型用途 |
|------|------|----------|
| 群组营销 | `TG群组自动营销` | 向已加入的**群组**群发消息 |
| 频道营销 | `TG频道自动营销` | 向**频道帖子**发表评论 |

## 2. 目录准备

首次运行后软件会自动创建以下文件夹（也可手动创建）：

```
程序目录/
├── config/          # Configuration.ini 授权配置
├── 账号/            # 放置 *.session
├── log/             # 运行日志
├── 异常账号/        # 失效 session（自动移入）
├── 双向限制账号/    # 已确认双向（自动移入）
└── 无群组账号/      # 仅群组营销：无可发群（自动移入）
```

## 3. 放入账号

1. 将 Telethon 或已转换的 `.session` 文件复制到 `账号/`
2. Pyrogram 格式 session 在加载时会**自动转换**为 Telethon（无需手动操作）
3. 启动软件，输入**授权码**与**端码**，登录成功后再选功能
