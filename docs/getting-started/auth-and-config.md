# 授权与配置

## 首次登录

1. 启动 exe，按提示输入 **授权码**、**端码**
2. 登录成功后信息写入 `config/Configuration.ini`
3. 窗口标题会显示 masked 授权码、端码、到期时间

## Configuration.ini 常见字段

| 字段 | 说明 |
|------|------|
| `client_token` | 授权码 |
| `client_code` | 端码 |
| `api_id` / `api_hash` | Telegram API（群组小号群发等使用） |
| `channel_ID` | 小号群发默认频道用户名（`广告.txt` 为空时的回退来源） |
| `delay` | 默认间隔（部分功能） |
| `header` | 小号群发发送方式：`转发` / `直发` |

> 具体字段以软件版本为准，缺失时启动过程会提示输入。

## 授权失败

| 现象 | 处理 |
|------|------|
| 产品授权码验证失败 | 检查授权码，配置文件可能被清空需重填 |
| 授权码已过期 | 联系客服续费 |
| 网络连接异常 | 检查网络，按 Y 重试 |

## 软件更新

* **群组营销**：主菜单 → `3.更新`
* **频道营销**：功能菜单 → `12.检测更新`

发现新版本后会自动下载，无需确认 Y/N。
