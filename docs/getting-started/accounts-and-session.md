# 账号与 Session

## session 文件

* 路径：`账号/你的账号名.session`
* 一个 session 对应一个 Telegram 用户号
* 附属文件 `-journal`、`-wal`、`-shm` 由 SQLite 自动生成，移动账号时会一并处理

## 支持的格式

| 格式 | 说明 |
|------|------|
| 本框架协议 | 标准格式，直接使用 |
| 本框架协议旧版 | 缺少 `version` 表时自动修复 |
| 其他框架协议 | 加载时自动转为本框架协议 |
| 无效/损坏 | 移入 `异常账号/` |

## 账号归档文件夹

| 文件夹 | 触发条件 |
|--------|----------|
| `异常账号/` | 未授权、冻结、session 损坏、顶号等 |
| `双向限制账号/` | SpamBot 确认账号级双向限制 |
| `无群组账号/` | 群组营销：没有可发消息的群 |

> `异常账号/`、`双向限制账号/`、`无群组账号/` 在首次移入对应账号时自动创建，并非启动时全部预建。

## 检测账号

两套软件均提供 **检测账号**，菜单序号不同：

| 产品 | 菜单 | 流程 |
|------|------|------|
| 群组营销 | **01**.检测账号 | 加载 session → 可选 SpamBot 双向检测 → 异常号自动移走 |
| 频道营销 | **06**.检测账号 | 同上 |
